## PROJECT NOTES

Even though I've already completed the restaurant project just before delving into this iteration, this experience WAS insightful, specifically for certain CSS nuances I haven't considered before. Since I've adapted this page to mobile view (which I haven't really done before), I had to thoroughly think out sizing and placement of all page elements so that they wouldn't require manual adjustment for bazillion variations of page width - and I'm quite happy with what i've made in the end. 

The hardest problem of this entire project was its scrolling issue - which I haven't encountered previously due to not making mobile-ready sites or sites which had enough content to warrant scrolling on Y axis in any of my previous projects. And the root of the problem turned out so simple - I just shouldn't have set the height of the body element to 100%, as that disables its scrolling events. The more you know!
